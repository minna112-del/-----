# গোলাপি নিউজ (Golapi News) - Deployment & Setup Guide

**“গোলাপি নিউজ”** একটি আধুনিক, দ্রুততম, মোবাইল-ফার্স্ট ও এসইও-বান্ধব সম্পূর্ণ বাংলা ডিজিটাল সংবাদপত্র পোর্টাল।

---

## 📁 ফাইল ও ফোল্ডার পরিচিতি
```text
├── index.html          # হোমপেজ (ব্রেকিং নিউজ টিকার, লিড নিউজ, ক্যাটাগরি গ্রিড, অ্যাডসেরা ব্যানার)
├── article.html        # নিউজ ডিটেইল পেজ (বড় ছবি, লেখক, সোশ্যাল শেয়ার, ইন-আর্টিকেল ব্যানার)
├── style.css           # আধুনিক বাংলা টাইপোগ্রাফি (Hind Siliguri) ও ডিপ রোজ কালার থিম
├── app.js              # ডাইনামিক ডেটা লোডার, ক্যাটাগরি ফিল্টারিং, সার্চ ও সোশ্যাল শেয়ার স্ক্রিপ্ট
├── news-data.json      # সকল নিউজ, ক্যাটাগরি, ব্রেকিং নিউজ ও সাইট সেটিংসের লাইভ ডেটাবেস
├── netlify.toml        # Netlify ক্যাশিং, সিকিউরিটি ও হেডার রুলস
└── README.md           # সম্পূর্ণ সেটআপ নির্দেশিকা
```

## 🚀 ১. Netlify Drop-এ সরাসরি ডিপ্লয় করার নিয়ম (১ মিনিটে লাইভ):
1. ব্রাউজারে [https://app.netlify.com/drop](https://app.netlify.com/drop) ওপেন করুন।
2. আপনার ফ্রি Netlify অ্যাকাউন্টে লগইন করুন।
3. এই সমস্ত ফাইলসহ ফোল্ডারটি সরাসরি ড্র্যাগ করে আপলোড বক্সে ছেড়ে দিন।
4. মাত্র কয়েক সেকেন্ডের মধ্যে আপনার পোর্টাল লাইভ হয়ে যাবে (যেমন: `golapinews.netlify.app`)।
5. Netlify সাইট সেটিংস থেকে খুব সহজেই আপনার নিজস্ব কাস্টম ডোমেইন (যেমন: `golapinews.com`) যুক্ত করতে পারবেন।

## 💰 ২. Adsterra বিজ্ঞাপন সেটআপ ও কোড বসানোর স্থান:

| বিজ্ঞাপনের ধরন | ফাইলের নাম | সঠিক স্থান |
|---|---|---|
| **Popunder Code** | `index.html` & `article.html` | `<head>` ট্যাগের ঠিক ভেতর |
| **Social Bar Code** | `index.html` & `article.html` | `<body>` ট্যাগের শুরুতেই |
| **Header Banner (728x90)** | `index.html` | `<header>` সেকশনের `.header-ad-space` ডিভে |
| **Sidebar Banner (300x250)**| `index.html` & `article.html` | `<aside class="sidebar-right">` সেকশনে |
| **In-Article Banner (468x60)**| `article.html` | আর্টিকেলের মূল বডির মাঝখানে `.adsterra-infeed-ad` ডিভে |
| **Footer Banner (728x90)** | `index.html` | ফুটারের ঠিক উপরে `.footer-ad-container` ডিভে |

*টিপস: গোলাপি নিউজ অ্যান্ড্রয়েড অ্যাপের অ্যাডমিন প্যানেলে ঢুকে **"অ্যাডসেরা বিজ্ঞাপন"** সেকশন থেকে কোনো কোডিং ছাড়াই সরাসরি কোড পেস্ট করে আপডেট ফাইল এক্সপোর্ট করতে পারবেন!*

## 📱 ৩. Facebook Share Preview (Open Graph) ঠিক রাখার নিয়ম:
- প্রতিটি সংবাদের হেডারে ওপেন গ্রাফ ট্যাগ যুক্ত রয়েছে:
  ```html
  <meta property="og:title" content="সংবাদের শিরোনাম" />
  <meta property="og:description" content="সংবাদের সারসংক্ষেপ" />
  <meta property="og:image" content="https://domain.com/image.jpg" />
  <meta property="og:url" content="https://domain.com/article.html?id=123" />
  ```
- **সঠিক প্রিভিউ না আসলে:** [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/) পেজে গিয়ে সংবাদের লিংক পেস্ট করে **"Scrape Again"** বাটনে ক্লিক করুন। ফেসবুক সাথে সাথে ইমেজ ও বিবরণ ক্যাশ আপডেট করে নেবে।

## 🔄 ৪. ভবিষ্যৎ আপডেট করার নিয়ম:
1. গোলাপি নিউজ অ্যাপের অ্যাডমিন প্যানেলে লগইন করুন।
2. নতুন সংবাদ যোগ করুন, এডিট করুন বা ব্রেকিং নিউজ পরিবর্তন করুন।
3. **"নেটলিফাই লাইভ ফাইলস"** মেনু থেকে **"Export news-data.json"** ডাউনলোড করুন।
4. ফাইলটি Netlify-তে রিপ্লেস করলেই সম্পূর্ণ ওয়েবসাইট তাৎক্ষণিকভাবে আপডেট হয়ে যাবে!
